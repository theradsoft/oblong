# oblong documentation

oblong is a keyboard-driven window manager for Windows 10 and 11, inspired by Rectangle on
macOS. It's a single AutoHotkey v2 script.

## Quick start

1. Install [AutoHotkey v2](https://www.autohotkey.com).
2. Put `oblong.ahk` and `oblong.ico` in a folder you'll keep and double-click `oblong.ahk`.
3. Press **Ctrl+Alt+E** to snap the active window to the left half; press it again for the
   right half.
4. Double-click the tray icon to change shortcuts and settings.
